# Governance

GoPGRoute is an independent open-source project maintained in ioplane.

| Area | Policy |
|---|---|
| Default branch | master; accepted changes through pull requests after bootstrap |
| Maintainer | [Pavel Lavrukhin](https://github.com/dantte-lp) |
| License | Apache-2.0 |
| Versioning | Semantic Versioning; immutable tags; no initial runtime release |
| Changelog | Keep a Changelog, English and Russian |

Create integration and release branches when they are needed. Publication
requires a reviewed exact commit, passing relevant checks and complete,
verified artifacts. Never label a design-only repository production-ready.
