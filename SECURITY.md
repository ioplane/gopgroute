# Security policy

Do not publish vulnerabilities, credentials or private deployment evidence in
issues or pull requests. Report vulnerabilities through
[GitHub private reporting](https://github.com/ioplane/gopgroute/security/advisories/new).
Include affected commit, impact and a synthetic reproducer.

No runtime release currently exists. Future security review must cover
untrusted health responses, GoBGP authorization, route ownership, stale state,
process failure and fencing assumptions.
