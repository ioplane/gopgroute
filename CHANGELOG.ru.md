# История изменений

## [Unreleased]

### Исправлено

- Повторный запуск guardian использует наследуемые runtime/journal locks и
  новые каталоги инкарнации без передачи прежних UUID новому speaker. Старые
  журналы сохраняются; плоское legacy-состояние требует отдельной миграции.
  Контейнеры route в лаборатории повторяют аварийный запуск до трёх раз.

### Безопасность

- Компилятор Go 1.27.4 устраняет GO-2026-6859 в runtime и SQL fixtures.
  Выбор runtime toolchain запрещает скачивание запасного компилятора;
  закреплённый formatter/linter сохраняет собственный компилятор анализа.

### Добавлено

- Изолированный стенд Podman Compose: три PostgreSQL/Patroni, etcd, PgBouncer,
  GoPGRoute/GoBGP, FRR leaf и SQL/PowerDNS-клиент через сервисные VIP. Проверки
  различают роли и подтверждённые транзакции; автоматический restart с прежним
  журналом владения остаётся отдельным критерием приёмки.

- Клиент GoBGP через private Unix socket: журнал UUID, точный отзыв,
  блокировка при неопределённости и нативные тесты потери ответов и рестартов.
- Контракт владения и ADR 0002 на английском и русском; допуск runtime
  зависит от независимого супервизора выделенного speaker.
- Ограниченные HTTP/TLS-проверки Patroni, строгая проверка ответов и политика
  допуска по свежести; race tests и проверки безопасности в контейнере.
- Контракт здоровья, ADR 0001 и треки реализации на английском и русском.

- Документация публичного проекта, правила именования, участия и проверки
  репозитория для проекта адаптера Patroni → GoBGP.
