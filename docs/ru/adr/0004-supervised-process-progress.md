# ADR 0004: Независимый контроль выполнения

Статус: принято для внутренних компонентов T3.2; production admission не выполнен.

## Контекст

Журнал маршрутов может зависнуть на filesystem I/O. Адаптер способен завершиться
или остановиться при продолжающемся анонсе выделенного GoBGP speaker. Штатный
shutdown hook и отдельный heartbeat timer не обеспечивают ограниченный отзыв.

## Решение

Отдельный Linux guardian владеет прямыми процессами speaker и адаптера.
Закрытый унаследованный pipe передаёт progress только после полного успешного
цикла сверки. Выход ребёнка, отказ progress или timeout останавливают оба
принадлежащих process handles с ограниченным TERM/KILL ожиданием. Parent-death
signals привязывают детей к закреплённому создавшему thread guardian.
Автоматические restart детей и reset route journal запрещены.

## Последствия

Guardian управляет одной speaker incarnation, совместное использование с
другими сервисами запрещено. Планирование guardian и progress ядра остаются
предпосылками. Связка демона, проверенный startup, восстановление журнала,
peer GR/клиентские результаты и Patroni/DCS/watchdog fencing требуют отдельной
приёмки. Точный контракт и тесты — в
[описании progress](../05-supervised-progress.md).
