# Contributing

Use focused pull requests against master and Conventional Commits. Read
[the architecture](docs/en/01-architecture.md) and update the changelog for
user-visible changes. Maintainers review safety boundaries, validation and
security before merge. Runtime changes require tests and container-based
checks; bootstrap whitespace checks alone do not qualify runtime code.

Public examples must use synthetic identities and documentation addresses.
Do not include deployment inventory, credentials or private evidence.
